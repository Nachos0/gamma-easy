# Roadmap

## Before a stable release

- [x] Complete a real installation and receive confirmation of an in-world launch (2026-10-09).
- [ ] Validate extended gameplay, save/load, and a fresh install on another machine.
- [ ] Validate standard-user and alternate-account UAC handoff.
- [ ] Exercise interrupted downloads/extraction, mirror failures, and recovery.
- [ ] Verify Microsoft prerequisites, restart behavior, and update/save preservation.
- [ ] Resolve any installation blockers discovered in those tests.

## Usability

- [ ] Clear phase labels and overall progress where the backend exposes reliable totals.
- [ ] Better guidance for mirror or antivirus failures.
- [ ] Windows uninstall registration for the launcher.
- [ ] Import a verified clean existing Anomaly installation.
- [ ] Configurable advanced download concurrency.

## Distribution

- [ ] Sign Windows executables.
- [ ] Verify public release downloads against source builds.
- [ ] Add update notifications with an explicit user-controlled update action.

## Optional co-op after the base installation works

- [x] Research xrRazom, Anomaly Together 2, and other candidates; publish the comparison.
- [ ] Compare two-player behavior before selecting a supported provider.
- [ ] Validate xrRazom against the installed GAMMA version and identify its required tweaks.
- [ ] Implement optional post-install co-op setup from a verified upstream release.
- [ ] Add a reversible Single-player / Co-op switch covering both engine files and MO2 profiles.
- [ ] Handle compatibility checks, saves, and GAMMA repair/update interactions.
- [ ] Test hosting/joining and switching back before enabling the toggle for users.

See the [xrRazom integration plan](COOP.md). This feature is planned, not installed
or supported in the current release.

Candidate evidence and proposed app improvements are in the
[co-op comparison](COOP-COMPARISON.md).

These are planned improvements, not shipped features or release dates.
