# Roadmap

## Before a stable release

- [ ] Complete a real fresh installation and MO2/DX11 gameplay test.
- [ ] Validate standard-user and alternate-account UAC handoff.
- [ ] Exercise interrupted downloads/extraction, mirror failures, and recovery.
- [ ] Verify Microsoft prerequisites, restart behavior, and update/save preservation.
- [ ] Resolve any installation blockers discovered in those tests.

## Usability

- [ ] Clear phase labels and overall progress where the backend exposes reliable totals.
- [ ] Better guidance for mirror or antivirus failures.
- [ ] Windows uninstall registration for the launcher.
- [ ] Import a verified clean existing Anomaly installation.
- [ ] Configurable advanced download concurrency.

## Distribution

- [ ] Sign Windows executables.
- [ ] Verify public release downloads against source builds.
- [ ] Add update notifications with an explicit user-controlled update action.

These are planned improvements, not shipped features or release dates.
