# GAMMA Easy 0.1.0 — Early alpha

An independent Windows setup and launcher for Anomaly + GAMMA.

**Download:** `GammaEasy-0.1.0-windows-x64.zip`. Extract it and run `GammaSetup.exe`.
Requires Windows 10/11 x64, .NET Framework 4.8, and about 200 GB free on an internal
NTFS drive. The executable is unsigned.

Choose a drive, click Install, and launch through Mod Organizer when the checks
finish. The app includes stop/retry, cached archives, required-file/profile checks,
optional Defender folder exclusions, and verified Microsoft runtime downloads.

The game and modpack are downloaded from their upstream sources, not bundled.
Thanks to Grokitach/GAMMA, FaithBeam's installer engine, the Anomaly team, MO2,
7-Zip, and the mod authors.

**First-build limit:** isolated checks passed locally; the full game installation,
system runtime installation, UAC handoff, and actual game launch have not been
tested end to end. This is a prerelease for testing, not a proven stable installer.

The matching app/backend/native dependency source is in
`GammaEasy-0.1.0-source.zip`. SHA256 checksums accompany both ZIP files.
