# GAMMA Easy 0.1.1 — Verification fixes

Fixes the final-check failure after the backend reports Install finished:

- Corrects the known upstream DarkasleQif/Darkasleif mod-name mismatch when the
  enabled misspelled entry is present and the actual mod payload exists.
- Accepts the Windows game-path format MO2 writes to its configuration.
- Adds Verify to check an already completed installation without downloading or
  extracting again. The completed backend log must match the selected drive.
- Optional cached-archive MD5 audit is off by default and can be stopped. Full
  installer runs still perform the backend's required integrity checks.

Close Mod Organizer and GAMMA Easy before updating the launcher. Install this
version, then click Verify. Existing game files and cached downloads are retained.

This is still an unsigned alpha. Verification checks are tested; actual gameplay
and co-op have not yet been validated. Corresponding source and checksums accompany
the Windows package.
