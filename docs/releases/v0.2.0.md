# GAMMA Easy 0.2.0 — Optional co-op alpha

Optional xrRazom 1.4 setup, separate MO2 profile, reversible Single-player / Co-op
switching, backups, recovery and read-only friend comparison. Setup stays inactive
until Co-op is selected. Official Slim or Full ZIPs are accepted; Full uses core
files only. No game or co-op payload is redistributed in releases.

Close the launcher, Anomaly and MO2 before updating. See the
[co-op guide](https://github.com/Nachos0/gamma-easy/blob/main/docs/COOP.md).
Use distinct save names; profiles may share the Anomaly saves folder.

52 isolated checks and the authenticated Full Bundle fixture passed. Two-player
host/join and extended stability remain unvalidated. This is an unsigned alpha.

Thanks to xrRazom's author and Commander integration documentation used for
research. The integration is original code; no co-op binary is bundled.
